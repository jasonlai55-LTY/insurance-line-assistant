# 保險業務 LINE 助手系統規格 (PRD)

## 1. 系統目標
打造結合「LINE 官方帳號 (OA) + LIFF 前端 + CMS 管理後台 + 後端 Webhook」的保險業務賦能平台，降低業務員獲取商品與行政資訊的摩擦力，並提供分眾推播提醒。

## 2. 三大核心架構與模組
### (A) 後端服務 (LINE Webhook & Core API)
- 技術選型：FastAPI (Python) 或 NestJS (Node.js) + PostgreSQL。
- LINE Signature 驗證與 Webhook 事件處理。
- 關鍵字/商品代號查詢 (回傳 Flex Message 卡片)。
- Push/Multicast 訊息推播排程與記錄。

### (B) 業務員端 (LIFF 輕應用)
- 身份驗證機制：工號 + 簡訊 OTP 雙重綁定與權限檢查。
- 商品專區：DM、銷售手冊、推廣影片、條款線上預覽與一鍵轉發 (Share Target Picker)。
- 行政規範庫：投保規則、保全規則、理賠指引、各式申請表單下載。
- 個人通知中心：按類別（行政照會、商品異動、營運活動）歸檔歷史通知。

### (C) 通路管理後台 (Web CMS)
- 素材與表單管理：支援分類、上架/下架、版本過期警示。
- Excel 批次匯入發送個別通知（需包含防呆校驗）。
- 分眾標籤管理（依通路、通訊處、職級進行分群）。

## 3. 資安與合規底線 (Strict Constraints)
- **個資脫敏**：照會訊息明文嚴禁包含完整客戶姓名、身分證字號或病歷資訊（需掩碼處理）。
- **內部文件防護**：核保手冊、特定銷售手冊僅限驗證過工號的業務員瀏覽。
- **推播成本控制**：被動查詢走 Reply/LIFF，只有緊急或特定個人通知走 Push Message。
